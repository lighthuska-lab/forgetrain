# Contributing

Use Python 3.12+, create a feature branch, install with `pip install -e .`,
and run `python -m unittest discover -s tests`. Run Ruff lint/format and build
the package before requesting independent review. Explain actual test results,
limitations and the issue addressed. Preserve attribution. Do not report model
or GPU experiments without retained evidence. Public publishing, releases and
production deployment require the owner's approval.
